Powered-lab integration evidence

The complete opening uses Factorio **2.1.17**, observer **0.3.0**, a normal connected player
and finite proving-ground inventory. Character **#12** retains the original stock. Native cursor
building creates furnace **#14** and six power-island entities **#15–20**. No entities used for
construction are created through `surface.create_entity`; that API is confined to world/character
setup. Recipes, smelting, mining, steam generation and research all advance normal game ticks.

The successful physical construction runs at `/tmp/blueprint-gen-power-01` and `-02` completed
Automation. Their initial electric instrumentation read the wrong statistics direction, so the
second run correctly refused a success report at its new verification step. A separate read-only
inspection of its paused save found **6,001,066.67 J** in the lab input counter and the same value
in the engine output counter. The final runner uses those engine-defined directions. It never
modifies statistics to repair a result.

Canonical current evidence in `fixtures/` comes from the fully verified, relocated-pond run
`/tmp/blueprint-gen-power-shifted-01`. Its default-pond control is `/tmp/blueprint-gen-power-03`;
that control's observed result also passes the current verifier. The comparison keeps raw
default final state and verification alongside the shifted run:

| File | What it establishes |
| --- | --- |
| `final-observation.json` | Capture-bound research, native inventory, network membership, steam and lab state |
| `actions.json` | 85 commands, including three expected placement refusals and 6,000 ticks of lab research |

| `default-final-observation.json`, `default-verification.json`, `default-recording-summary.json` | Default shoreline control and the locally exported demonstration video |

The previous headless default was rerun at `/tmp/blueprint-gen-power-baseline` with the empty
extension hooks. It retained its original finite-stock, restart and uncredited-lab result.

`shifted-pond.json` moves the pond eight tiles east and twenty south without changing starter
stock or resource patches. The physical test moved all six power entities by that offset and
preserved the bills, final inventory, 60 kW lab load and completed Automation research.
Pass it with `--config 10_powered_lab/integration/shifted-pond.json` to exercise another shoreline.

Electric averages use `get_flow_count` with the five-second precision and convert joules/tick
to kW by multiplying by 60/1000. Electricity's `input` side is the consuming lab, and its `output`
side is the generating engine. Cumulative energy is read separately. No prototype generation
rating is treated as measured delivery or as an infinite fuel supply.

Native recordings remain local under `10_powered_lab/out/recording/`; raw PNGs and logs are kept
in the disposable run directory. Screenshots are generated by Factorio, and renderer overlays
are bound to each image's request-tick observation. The source manifest requires every image.

This is an authored rectangular-shore method, not general layout search. The three-coal boiler
budget is exhausted at the end, while steam remains in the engine. Ten red science packs were
handcrafted for research; this is not a sustained automated science production measurement.
