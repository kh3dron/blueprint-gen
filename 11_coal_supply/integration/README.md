Coal supply integration

The scenario overlay wraps the existing native player, construction and power controller.
`extension.lua` observes coal entities and supports paid seeding, timed idle measurement,
and native tree harvesting. `adapter.lua` supplies a separate registry to the cursor adapter.
`control.lua` preserves native build/crafting capture and adds native tree-mining events.
It does not grant inventory, resource replenishment, recipe unlocks or energy.

Default-world evidence was generated by `/tmp/blueprint-gen-coal-02` on Factorio 2.1.17.
After one startup minute, the five observed delivery rates were 12, 13, 13, 11 and 13 coal/min.
The powered-lab checkpoint also passed its original inventory, native event and research checks
using this experiment's extended runtime catalog. These fixtures omit the observer player's
display name; all gameplay facts are retained.

| Fixture | Evidence |
| --- | --- |
| `final-observation.json`, `verification.json` | Verified powered-lab checkpoint before the continuation |
| `coal-design.json`, `coal-materials.json` | Survey-derived placements and runtime construction costs |
| `actions.json`, `player-crafts.jsonl` | Full command ledger and native crafting events |
| `coal-reconciliation.json` | Repeat deployment and direction-drift refusal |
| `coal-warmup.json` | Entire startup minute, including its lower initial output |
| `coal-windows.json` | Five contiguous idle minutes, native endpoints, deposit and buffer counts |
| `coal-final-observation.json`, `coal-verification.json` | Final world, native build/tree events and checked accounting |
| `performance.json`, `recording-summary.json` | Simulation/wall timing and complete native recording metadata summary |
| `shifted-design.json`, `shifted-final-coal.json`, `shifted-verification.json`, `shifted-performance.json` | Physical translation control, with identical costs and delivery rates |

The translation control is `/tmp/blueprint-gen-coal-shifted-01`, using `shifted-coal.json`.
It takes 84,337 ticks (1,405.62 simulated seconds) and 173.88 wall seconds at requested 10×.
Both runs finish with 68 coal in the chest, after 6 startup coal plus 62 during measurement.

The runtime marks belts and containers `active=false` even when they function normally;
only the drill/inserters use that operating flag in this verifier. Newly built, unpowered
drills can have no `drop_target` until simulation runs. The verifier requires resolved
native connections after startup, and throughout all five delivery windows. Burner inserters
receive their normal initial wood energy from the base game; that energy is observed and
included in the seed budget, not overwritten by the scenario.

Compact verified artifacts belong in `fixtures/`. Raw PNGs, logs, saves and media remain
in the disposable run directories or the ignored `../out/` directory. Player account names
and raw client logs should not be copied into fixtures.
